🗓️ Programação Semanal

Controla a tabela de atividades exibida na tabela Programação de Campo. Uma linha "Automática" busca o dirigente numa lista de rotação (existente ou nova); "Manual" usa o texto digitado. Sem nenhuma linha aqui, o site mostra a tabela padrão.

📋 Listas Customizadas

Listas de rotação criadas a partir de uma linha "Automática" da Programação Semanal, para dias além de sexta/sábado/domingo. Exemplo: Se na programação semanal você tiver uma linha "Domingo (Manhã) - Automática (Lista Domingo)", uma lista chamada "Domingo" será criada automaticamente e poderá ser usada em outras partes do sistema.

Nenhuma lista customizada ainda.
